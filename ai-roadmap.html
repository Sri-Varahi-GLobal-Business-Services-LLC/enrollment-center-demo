✨ ML recommends — the rules engine decides

Summary of the AI/ML Roadmap v1.1 for the Customer Enrollment Center (SAP Service Cloud V2 + SAP BTP + S/4HANA Utilities). Hard eligibility always comes from auditable BRFplus decision tables; AI ranks, explains and predicts — with the agent in the loop. Demo scores are illustrative seed values.

How the AI score is calculated

The percentage is a calibrated enrollment probability — the likelihood this customer enrolls in the program if offered:

  1. Training data — the system labels its own examples: every offer shown plus the outcome (enrolled within 30 days or not).
  2. Features — meter type and status, DER equipment, payment behavior, arrears, program history, usage pattern.
  3. Model — classification (SAP HANA Cloud PAL/APL) turns features into a raw probability.
  4. Calibration — adjusted so the number means what it says: of customers scored 87%, about 87% actually enroll.
  5. Reason — the explanation under the badge comes from the model’s top contributing factors, never free text.
  6. Ranking — sort order weighs probability × program value.

Cold start: go-live runs on weighted business rules, swapped for the trained model after 3–6 months of outcomes.
